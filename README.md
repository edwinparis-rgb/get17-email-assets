## Règles

- **Ne jamais supprimer ni renommer** un fichier déjà utilisé dans un envoi : les emails reçus continuent de l'afficher.
- **Une image modifiée prend un nouveau nom** (`-v2`, `-v3`…) ; l'ancienne reste en ligne.
- **Rien d'autre ici** : ni capture d'écran (client ou démonstration), ni historique, ni donnée, ni clé. Un dépôt public garde tout son historique.
- Toujours utiliser l'URL GitHub Pages ci-dessus, jamais `raw.githubusercontent.com`.
